# Symptom to Specialization Mapping

Use this mapping to recommend doctors:

- Fever → General Physician
- Cough, cold, throat pain → ENT or General Physician
- Chest pain → Cardiologist
- Stomach pain → Gastroenterologist / General Physician
- Skin rash → Dermatologist
- Eye redness → Ophthalmologist
- Back or joint pain → Orthopedic
- Urinary burning → Urologist
- Headache, dizziness → Neurologist
- Diabetes issues → Endocrinologist

Rules:
- If unsure, recommend General Physician.
- Use only these mappings. Do NOT infer new ones.
