# Agents

This folder contains the backend agent modules used by the application.

## Files

- `diagnostic_agent.py` - Handles diagnosis-related agent logic and workflow.
- `llm_config.py` - Defines LLM configuration and model settings.
- `mcp_tools.py` - Contains helper functions for interacting with the MCP toolset.
- `orchestrator.py` - Coordinates agent execution and request routing.
- `pipecat_pipeline.py` - Implements the pipeline for processing user inputs and agent outputs.
- `symptom_lookup.py` - Provides symptom lookup and related medical inference logic.
- `triage_agent.py` - Manages triage-related decision-making and recommendations.
- `voice_agent.py` - Handles voice assistant interactions and voice-specific functionality.

## Purpose

These modules work together to support the AI-driven backend in the project, including symptom analysis, triage, voice interaction, and LLM orchestration.
